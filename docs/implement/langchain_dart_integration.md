# LangChain.dart 与 AI 助手实现

本次实现设计文档的首次接入范围：云模型配置、独立协议测试、流式文本、宿主控制的工具循环、Gateway、会话与操作记录持久化，以及真实媒体查询和基础播放控制。

## 使用

1. 打开「设置 → AI 助手 → 模型设置」，填写 HTTPS API 基址（通常含 `/v1`）、模型 ID 与 API Key。
2. 分别测试普通回复、流式回复、工具调用。测试只发送固定探测提示，不执行业务工具；探测本身会使用供应商 API 配额。工具测试通过并保存后才向模型提供业务工具。普通回复已验证而流式未验证时使用非流式对话。
3. 勾选云端数据授权并保存。供应商、模型、凭据或参数变更会清除探测状态和授权，需重新选择。
4. 在首页 AI 区域或右下角 Lucide 助手按钮打开会话；两处共享同一协调器。关闭面板继续执行，停止生成则禁止后续工具。
5. 如需聚合远程搜索，在「设置 → 来源 → 默认来源」的多源搜索范围选择 Plex/Jellyfin。未选择的实例不参与搜索。本地文件夹/SMB 使用扫描到媒体库的数据。

仅实现 OpenAI 协议 Provider；兼容端点需通过实测，不根据 URL 推断能力。直接声明并锁定 `langchain_core 0.5.0`、`langchain_openai 0.9.0`，以及用于类型化错误映射的 `openai_dart 8.1.0`。版本/API 已核对 [Provider 文档](https://pub.dev/packages/langchain_openai) 与安装版本源代码。

## 边界

- `core/models/text_model.dart` 定义供应商无关消息、调用、文本/工具片段、完整调用、结束原因和实际用量。LangChain 类型仅存在于 `plugins/model_langchain`。
- SDK `ChatResult.concat()` 组装交错的工具参数。片段不能执行；完整流、有效结束原因及 JSON/Schema 验证均通过后才交给业务。截断回复标为失败并保留已显示文本。
- `ConversationCoordinator` 每个会话只运行一个回合；上限为 8 次模型调用、12 次工具调用、120 秒，单次模型等待 45 秒、工具等待 20 秒。工具执行串行，多源搜索最多并行 3 个 Provider。
- 云端上下文为页面名称、播放快照及有界会话历史。完整历史回合按 24000 字符截取，当前请求总量限制为 64000 字符；这是保守字符限制，不伪称精确 token 计算。供应商报告用量另按每回合 32000 token 限制；无用量时不显示虚构的数字。
- 单个工具参数最多 16384 字符、结果最多 24000 字符；常规查询每页最多 20 项。搜索一次最多查询 12 个已选择来源。
- Gateway 使用同一输入定义生成 Schema 和本地校验，拒绝未知工具、额外字段、错误类型、负数与过期引用。模型不提供身份、确认凭证、认证 Header、路径或 SQL。
- 来源浏览结果使用宿主内存中的不透明引用；媒体详情只返回数据库资源 ID。原始路径、来源地址、认证播放 URL 只供宿主与播放器使用。重启后的临时浏览引用失效，需重新查询。
- API Key 轮换到系统安全存储；SQLite 只保存凭据引用。云端发送须由设置 UI 授权。收藏变更等待 UI 确认；模型自报 `confirmed` 会被拒绝。
- 播放打开复用 `AppShell._play` 与 `PlayerPage.playSelection`；暂停、继续、定位、音量、倍速和停止使用同一个播放后端与进度记录。每次控制检查实际 session_id；打开资源返回提交状态及真实快照，不伪造播放已成功的事件。
- 副作用操作在 SQLite `assistant_operations` 先记 pending，后记脱敏结果。操作标识由宿主回合、执行意图版本、工具名与规范化参数摘要生成，连续重复提交跨供应商 call ID 去重；中间发生其他写入会产生新意图，因此暂停/继续/再次暂停不会被误去重。未知结果不自动重放；重启中断回合仅恢复展示。记录不与供应商 call ID 绑定为唯一身份。
- 取消与工具超时使异步执行标记失效；晚到解析结果不能再开始播放或发起后续搜索批次。已经完成的业务变更不撤销。
- 模型认证、限流、网络、协议与超时错误映射为安全错误码，不将 SDK 原始异常写入聊天。传统播放不依赖 AI 配置或模型在线。

## 已注册业务工具

`context_get`、`source_list`、`source_browse`、`library_list`、`library_query`、`media_get`、`search_media`、`progress_query`、`media_set_favorite`。

播放器后端可用时增加 `playback_get`、`playback_open`、`playback_pause`、`playback_resume`、`playback_stop`、`playback_seek`、`playback_set_speed`、`playback_set_volume`。工具总量不超过 20。

设计中的字幕、视觉、语义检索、转码、投屏、自动化等目录没有伪注册。本次也未把元数据修改与长任务工作流暴露给模型；后续应在各业务的授权、TaskRef 与卡片机制齐备后逐项接入。当前工具卡片显示脱敏结构化数据，支持 UI 确认；不执行模型生成的链接。

## 验证

```sh
flutter analyze
flutter test
flutter test test/ai
```

`test/ai` 覆盖真实 LangChain SDK 对本地 HTTP/SSE 替身的消息映射与交错拼接、截断与认证错误、Gateway Schema/过滤/确认/去重/超时、停止和预算、历史与操作记录恢复、多来源部分失败及并发上限、来源协议参数、旧播放会话拒绝、密钥轮换，以及首页与面板共享状态和窄屏大字体设置页。

测试不使用真实云模型凭据，不代表某个供应商账号或真实原生播放已经完成端到端验收。真实云连接通过应用内三个独立测试由用户按需验证；模型 API Key 不提供 TMDB、ASR 或字幕服务的权限。
