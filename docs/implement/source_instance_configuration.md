# 数据源与插件实例配置（设计 3.4）

当前实现覆盖已有本地目录、SMB、Plex、Jellyfin 四类内置插件，不新增 WebDAV、S3 或网盘连接器。

## 调用和存储

页面 → `SourceManager`（Plugin Manager）→ `SourceConfigurationService`（SQLite）及 `SourceCredentialBroker`（系统安全存储）。插件只获得当前实例的不可变配置快照、凭据引用和宿主创建的连接客户端；本地目录书签不传入插件，密码/令牌不进入配置 JSON。

添加表单参考 `design/research/vidhub-infuse-file-source-research.md` 收敛：本地目录使用系统选择器；SMB 默认仅显示地址、用户名、密码，路径和工作组折叠在“高级”；Jellyfin 使用用户名和密码登录，HTTPS、端口和子路径置于“高级”；Plex 使用官方 PIN 授权后选择服务器，不要求手工提取 Token。名称留空时自动采用文件夹、主机或服务器名。SMB 未指定共享目录时通过 listShares 浏览共享列表。

`SourceConnection` 负责把主机、端口、路径和安全方式组装到现有地址模型，接受粘贴完整 URL。`SourceSignIn` 负责 Jellyfin 登录及 Plex PIN、服务器发现和连接探测；Jellyfin 密码和 Plex 账号令牌只在内存中使用，安全存储仅保存对应服务器的会话凭据。旧的用户 ID/Token 配置继续可读，编辑原连接不要求重复输入。Plex 高级项保留手动连接以兼容既有配置。

版本、修订、逻辑绑定、到期时间、并发、目录白名单和扫描/后台索引参数不再出现在添加表单。后端管理策略保持不变，编辑连接时保留隐藏的既有值。

SQLite 文件位于应用支持目录的 `configuration.sqlite3`，包含：

- `plugin_instance_configs`：实例 ID、插件 ID、显示名称、逻辑来源绑定 ID、连接字段、启用意图、插件/配置版本、修订及策略。
- `config_applications`：期望修订、最近成功应用修订、待应用/初始化/就绪/失败/禁用状态，以及不含凭据的错误码。
- `settings`：设备级能力默认实例和多源搜索实例列表。

每次保存携带草稿的 `revision`，以 SQLite 事务检查并生成新修订。其他窗口已修改时返回冲突，不覆盖新数据。实例和默认绑定的删除/禁用同事务提交。旧 `source.instances.v1` shared preferences 只迁移一次，提交后才移除旧键；旧 Keychain 项保留原引用，无需重新输入账号。未知版本、未知字段及损坏实例被隔离并保留原 JSON，不阻止其他来源或本地播放器运行。

凭据轮换先创建新安全存储项，再提交新引用；数据库保存失败时清理未提交项，已提交后再清理旧项。编辑时凭据留空表示保留，不向插件返回明文机密。授权展示区分缺失、已保存未验证、已验证、认证失败、即将到期和已到期。到期日期由用户根据服务端信息填写；留空表示未知，不声称永不过期或自动续期。

## 生效与依赖

底层配置保存接口不自动联网；用户在添加表单提交时，表单先完成对应的连接验证或账号登录，再持久化实例。连接失败不创建半成品实例。Jellyfin 登录解析实际用户 ID；Plex 使用用户选定服务器的 accessToken，不把账号 Token 当作任意服务器凭据。当前连接与新实例之间不会静默切换账号。

实例按配置修订持有运行对象，每个运行对象独立限制请求并发（1–8）和调用超时（1–120 秒）。超时的底层操作在实际结束前仍占用并发槽，排队上限为 64，避免不断超时却持续增加物理并发。HTTP 浏览和播放代理共用对应实例的连接池。

禁用阻止新浏览和解析，不删除配置或凭据。编辑、禁用和删除将旧运行对象退休；已有请求及播放句柄使用原快照完成，所有句柄释放后销毁旧连接。界面在禁用/删除时说明活动播放、请求和默认绑定影响。删除只移除该实例配置、凭据引用及关联默认绑定，不删除用户文件、收藏或产物。尚未实现的业务 Repository 没有在这里建立假依赖计数。

有资源归属的解析始终路由到原实例。默认能力实例只用于无显式选择的入口；默认实例不可用时提示重新选择，不自动切换账号。媒体源页提供“默认浏览”入口。

## 目录与扫描

文件来源的 `allowedPaths` 是配置根目录内的相对目录白名单，空字符串表示整个根目录；多项取并集。允许浏览必要的父级，但过滤不在范围内的同级目录和文件；解析同时检查真实路径，符号链接不能绕过根目录或子目录限制。这些配置只能缩小既有系统授权，不能授予访问新目录的权限。

扫描支持手动和禁止两种模式。扫描预览应用访问范围和 `*` / `**` 排除规则，默认最多展示 500 个文件，并有 1000 次目录分页上限；离开页面取消预览。排除项只影响扫描，不代替访问权限。预览不写媒体库，也不生成持久索引任务。

已有四类插件均未提供 `search.media`、字幕搜索或后台索引。UI 明确说明这些功能不可用，不允许将不支持搜索的实例纳入聚合，也不暴露可开启的后台索引开关。搜索范围存储为实例列表，未来可接入多个真正支持搜索的实例；字幕搜索默认绑定在能力实现后开放。

## 验证

```sh
flutter analyze
flutter test
flutter test integration_test/source_storage_test.dart -d macos
```

真实 SMB、Plex、Jellyfin 服务的启动和初始化见 [临时服务说明](../../tool/source_services/README.md)。`sources_test.dart` 通过配置服务保存实例和凭据，按默认实例浏览、比较完整字节/Range，然后用 libVLC 播放并 Seek；播放过程中禁用实例，验证当前句柄仍可使用而新请求被拒绝。

账号授权的 HTTP 协议及 UI 流程由模拟服务和页面测试覆盖；真实 Jellyfin 账号登录及 SMB 共享枚举通过临时 Docker 服务验证。Plex 在线账号授权需要用户在官方页面完成，测试不会访问或代登录用户的真实账号。
