# 整部字幕生成

入口沿用开发者模式的“音频与字幕调试”页面。“生成整部字幕”使用当前选定音轨，
显示整部处理确认，完成后通过已有预览、保存和 SRT/VTT 导出操作处理结果。
不自动覆盖或加载字幕；保存后可以在播放器字幕列表选择。

设置 → 字幕 → 语音识别提供三种方式：

- Groq（免费，默认）：平台代理、V3，无客户端密钥或登录配置。
- 本地模型：用户主动下载/导入 whisper.cpp 模型。
- 自定义 API：支持 OpenAI-compatible `/audio/transcriptions` 和已有 OpenPlayX ASR 任务协议。

默认后端选择持久化。旧自定义服务按 OpenPlayX 协议解释；新配置默认 OpenAI-compatible。
AI 调用也遵循默认选择，不再自动从本地切换到其他上传服务。

## 客户端工作流

`SubtitleGenerationService` 负责所有分块和任务管理。超过 304 秒的识别区间按
300 秒的主体区间分块，两侧各保留最多 2 秒上下文；每块最多 304 秒。
每次只通过已有 FFmpeg 能力提取和识别一块 WAV，成功后释放该块音频。
短区间继续走已有单块流程；“仅提取音频”保持原有行为。

块内时间先映射到原始媒体时间。合并时收集重叠区全部候选段，排序并去重，
避免上游在切点两侧给出不同句子起点时，两份结果都因窗口归属被丢弃。
段级时间戳不是强制逐词对齐，电影噪音、混音和重叠对白仍会影响模型输出。

成功块的转录 JSON 以原子写入方式保存在应用字幕目录 `chunks/`，键包含资源引用、
探测指纹、音轨、区间、后端实例/地址/协议、模型/修订、语言及提取预设修订。
失败或取消后重新开始会复用完成块，应用重启也可复用；启动时清理超过 30 天的块缓存。
整部全部完成才发布完整转录，保存后才建立字幕绑定。

调试页离开时取消当前任务并清理未保存最终产物，保留已完成块检查点；
不承诺移动端后台持续执行。取消网络连接不保证上游未处理或未计费。
429 按 Retry-After 有限重试，断网/超时不自动重复付费调用；用户可以重新开始。

## 平台代理

默认地址为 `https://api.openplayx.com/v1/subtitles/transcriptions`。
仅上传规范化音频，不上传媒体来源地址或源站凭据。
Worker 的 `GROQ_API_KEY` 只存 Cloudflare Secret；服务器固定选择 V3，
验证 WAV 的真实格式和时长、限制请求大小、按 IP 限频，并使用独立全平台日保护上限。
不设个人每日免费额度。平台配置、错误及部署参见 API 仓库 README 的电影字幕章节。

## 验证

覆盖本地 HTTP multipart、秒到毫秒转换、取消限流等待、默认后端与设置持久化；
使用真实宿主 FFmpeg 加可控 ASR 验证长音频分块、跨切点重复句、原时间轴偏移、
失败后重启复用、取消不发布完整字幕，以及调试页确认、生成和保存流程。
Worker 单元和 workerd 集成测试覆盖 Groq 转发、WAV 时长验证、匿名调用和全局保护。
真实 Groq V3 已用经用户授权的 5.65 秒 en.wav 夹具验证带段级时间戳的响应；
不把此短样本验证当作真实电影识别质量或全部设备平台验收。
